# Test suites: what each one is for

Date-time: 2026-11-25T21:55:02Z (16:55:02, UTC-5).

The commands are in [docs/setup-and-testing.md](../../../docs/setup-and-testing.md). This note records the decisions behind the layout.

- **One Playwright runner, two suites.** `pnpm test:api` runs `tests/api` with the `request` fixture and never launches a browser. `pnpm test:browser` runs `tests/browser` in Chromium. A separate HTTP probe that needed no packages (`scripts/test-http.mjs`) was removed when API testing moved to Playwright.
- **Use the package scripts.** `testDir` is `tests/`, so a bare `playwright test` also collects the Vitest files in `tests/unit/` and the scanner test. It exits with an error and reports no tests (measured on 2026-11-25).
- **CI order.** The API suite runs before Chromium is installed and the browser suite runs after it, each as its own step. The audit check is its own job. An API regression fails early and cannot be mistaken for a browser failure. See `.github/workflows/ci.yml`.
- **The Playwright suite is a contract for contributors and agents, not an exercise for students.** Students learn from `docs/vulnerabilities/`. Every vulnerable route and every safe control gets a pair: one payload, its effect on the vulnerable route, and the same payload inert on the control. The "Playwright coverage contract" test in `tests/unit/catalog.test.mjs` enforces this.
- **A scenario batch shares one set of cases.** The first MongoDB batch reads `lib/mongo-cases.json` and `tests/mongo-cases.mjs`. The second reads `lib/workshop-cases.json` and `tests/workshop-cases.mjs`. The unit and API suites are built from the same cases, so a payload is written once.

**Why:** one runner keeps local work simple without making a browser binary a requirement for API testing, and the CI order keeps a failure attributable to one suite.

**Proving that the API suite needs no browser:** point `PLAYWRIGHT_BROWSERS_PATH` at an empty directory and run `pnpm test:api`. On 2026-11-25 all 196 tests passed and the directory stayed empty.
